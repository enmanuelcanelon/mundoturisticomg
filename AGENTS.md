## Cómo trabajar

1. Si es **estrategia/precio/prioridad** → C1  
2. Si es **campaña/copy/redes** → M1 / SM1  
3. Si es **cerrar venta** → V1 / CS1  
4. Si es **código** → O1 + B1/F1  
5. Dejar run en `agents/runs/`  
6. QA con T1  

## Principio

> Vender viajes con confianza: globo, destinos IATA, vuelos, hoteles, auth, reservas, marca MG, marketing y ventas alineados.
